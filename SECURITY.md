# Security

Word strings are rendered with `textContent`, not executable HTML. Imports are validated before replacing the stored list. There is no remote code, external vocabulary download or third-party runtime dependency. Website scripts can still interfere with DOM-based overlays; the extension is a voluntary learning aid, not tamper-proof parental control.

Please report a reproducible security issue through the repository's GitHub security reporting options if available. Do not post personal word lists or browser data in a public issue. Ordinary compatibility bugs can use Issues with redacted examples.
